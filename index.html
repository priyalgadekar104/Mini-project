What it does

Add, search and delete students

Records live in an Excel file. Roll numbers are checked for duplicates and marks must be between 0 and 100.

Grades and percentages

Total, percentage and a grade from A+ to F are worked out for every student.

Class and subject analysis

Class average, top and lowest performer, and the average, highest and lowest mark in each subject.

Graphs

A class chart of subject averages and grades, plus a bar chart for any single student.

Saved results

Export the full analysis to a new Excel file in one step.

The grading rule

Percentage is the total out of 500. The grade comes from this function.

def calculate_grade(percentage):
    if percentage >= 90:
        return "A+"
    elif percentage >= 80:
        return "A"
    elif percentage >= 70:
        return "B"
    elif percentage >= 60:
        return "C"
    elif percentage >= 50:
        return "D"
    else:
        return "F"
